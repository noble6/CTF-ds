# Challenge 08: Hidden Message
# Category: Forensics
# Points: 200
# Difficulty: Easy

## Description
There's a secret message hidden in this file. Can you find it?

[Provide a text file with flag hidden among garbage data]

## File Content (hidden_message.txt)
Create a file with random text, but embed the flag somewhere in the middle:

Lorem ipsum dolor sit amet...
[many lines of random text]
flag{hidden_in_plain_text}
[more random text]

## Flag
flag{hidden_in_plain_text}

## Solution
1. Use strings command: `strings hidden_message.txt`
2. Or search for "flag{": `grep -o "flag{.*}" hidden_message.txt`
3. Or open in text editor and search manually
