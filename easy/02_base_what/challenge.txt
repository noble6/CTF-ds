# Challenge 02: Base What?
# Category: Crypto
# Points: 100
# Difficulty: Easy

## Description
I found this encoded message, but I can't read it. Can you decode it?

ZmxhZ3tiYXNlNjRfaXNfdGhlX2ZpcnN0X3RoaW5nX3lvdV9sZWFybn0=

## Flag
flag{base64_is_the_first_thing_you_learn}

## Solution
This is Base64 encoding. Use any online decoder or Python:
```python
import base64
encoded = "ZmxhZ3tiYXNlNjRfaXNfdGhlX2ZpcnN0X3RoaW5nX3lvdV9sZWFybn0="
print(base64.b64decode(encoded).decode())
```
