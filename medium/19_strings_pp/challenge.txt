# Challenge 19: Anti-RE (Upgraded from Strings++)
# Category: Reverse
# Points: 450
# Difficulty: MEDIUM-HARD

## Description
This binary uses advanced obfuscation techniques to hide the flag. Simple `strings` won't work. Can you reverse engineer it?

**File:** `anti_re_binary`

## Obfuscation Techniques

### 1. Control Flow Flattening
- Normal if/else converted to switch-case with state variable
- Makes static analysis very difficult

### 2. Opaque Predicates
- Conditions that always evaluate to same value
- But looks complex to analyzer

### 3. String Encryption
- All strings encrypted with XOR
- Decrypted at runtime

### 4. Junk Code Insertion
- Dead code that never executes
- Confuses disassemblers

### 5. Anti-Debug Checks
- Detects debuggers and profilers
