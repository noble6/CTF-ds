## Description
I encrypted the flag using multiple cipher layers. Can you peel back all the layers?

**Ciphertext:** `Jx#5k9@p2m!Qw8^z`

## Encryption Layers (Applied in Order)

1. **Layer 1: Vigenere Cipher** (key: "college")
2. **Layer 2: ROT13**
3. **Layer 3: Reverse String**
4. **Layer 4: Atbash Cipher**

To decrypt, you need to reverse the operations!

## Cipher Descriptions

### Vigenere Cipher
- Polyalphabetic substitution
- Key: "college"
- Each letter shifted by key letter value

### ROT13
- Simple substitution
- Each letter shifted by 13 positions
- A→N, B→O, C→P, etc.

### Atbash Cipher
- Substitution cipher
- A↔Z, B↔Y, C↔X, etc.

### Reverse
- Simply reverse the string

## Solution

### Manual Approach
```python
def atbash(text):
    result = []
    for c in text:
        if c.isalpha():
            if c.isupper():
                result.append(chr(ord('Z') - (ord(c) - ord('A'))))
            else:
                result.append(chr(ord('z') - (ord(c) - ord('a'))))
        else:
            result.append(c)
    return ''.join(result)

def rot13(text):
    import codecs
    return codecs.decode(text, 'rot_13')

def vigenere_decrypt(cipher, key):
    result = []
    key_idx = 0
    for c in cipher:
        if c.isalpha():
            shift = ord(key[key_idx % len(key)].lower()) - ord('a')
            if c.isupper():
                result.append(chr((ord(c) - ord('A') - shift) % 26 + ord('A')))
            else:
                result.append(chr((ord(c) - ord('a') - shift) % 26 + ord('a')))
            key_idx += 1
        else:
            result.append(c)
    return ''.join(result)

# Decrypt in reverse order
ciphertext = "Jx#5k9@p2m!Qw8^z"

# Layer 4: Reverse Atbash
step1 = atbash(ciphertext)

# Layer 3: Reverse
step2 = step1[::-1]

# Layer 2: ROT13
step3 = rot13(step2)

# Layer 1: Vigenere
plaintext = vigenere_decrypt(step3, "college")

print(f"Flag: {plaintext}")
```
