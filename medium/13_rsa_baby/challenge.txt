## Description
I encrypted the flag using RSA, but I made some... unconventional choices. Can you break it?

## Challenge Variants (Choose One)

### Variant A: Wiener's Attack (Small Private Exponent)
```
N = large_number
e = very_large_number  # This is suspicious!
c = ciphertext
```
The private exponent `d` is very small, making it vulnerable to Wiener's continued fractions attack.

### Variant B: Multi-Prime RSA
```
N = p * q * r  # Three primes instead of two!
e = 65537
c = ciphertext
```
Using three smaller primes makes N easier to factor.

### Variant C: Common Modulus Attack
```
N = same for both
e1 = 3
e2 = 65537
c1 = pow(m, e1, N)
c2 = pow(m, e2, N)
```
Same message encrypted with different exponents, same modulus.

### Multi-Prime RSA
```python
# Factor N (smaller primes = easier)
from sympy import factorint

factors = factorint(N)
p, q, r = factors.keys()

phi = (p-1) * (q-1) * (r-1)
d = pow(e, -1, phi)
plaintext = pow(c, d, N)
```

### Common Modulus
```python
# Extended Euclidean Algorithm
def extended_gcd(a, b):
    if a == 0:
        return b, 0, 1
    gcd, x1, y1 = extended_gcd(b % a, a)
    return gcd, y1 - (b // a) * x1, x1

# Find m from c1, c2, e1, e2, N
_, a, b = extended_gcd(e1, e2)
m = (pow(c1, a, N) * pow(c2, b, N)) % N
```
