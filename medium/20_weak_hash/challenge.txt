## Vulnerabilities

### 1. No Salt / Same Salt
- All passwords use the same salt (or none)
- Rainbow table attack possible

### 2. Weak Salt
- Salt is short or predictable
- Can be brute-forced

### 3. Custom Algorithm
- Modified SHA-256 with weakness
- Collision easier to find

### 3. Brute Force (if salt is weak)
```python
import hashlib
import itertools

salt = "abc"  # Weak salt!
target = "5e884898da28047151d0e56f8dc6292773603d0d6aabbdd62a11ef721d1542d8"

for length in range(1, 6):
    for attempt in itertools.product('abcdefghijklmnopqrstuvwxyz', repeat=length):
        password = ''.join(attempt)
        hashed = hashlib.sha256((salt + password).encode()).hexdigest()
        if hashed == target:
            print(f"Found: {password}")
            break
```

### 4. Hash Length Extension
If the hash uses H(secret + message), you can extend it without knowing the secret.
