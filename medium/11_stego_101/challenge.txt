## Description
There are MULTIPLE secrets hidden in this image. The attacker used layered steganography to hide their tracks. Can you find ALL the hidden data?

**File:** `stego_master.png`

## Layers of Hidden Data

The image contains multiple hidden messages using different techniques:

### Layer 1: LSB (Least Significant Bit)
- Standard LSB steganography
- Extract using `stegsolve` or custom Python script

### Layer 2: Metadata (EXIF)
- Hidden data in EXIF fields
- Use `exiftool` to extract

### Layer 3: File Carving
- Another file embedded at the end of the image
- Use `binwalk` to extract

### Layer 4: Password Protected
- Some data is encrypted
- Password hint is in the metadata

## How to Create
```bash
# 1. Create base image
python3 generate.py

# 2. Embed data using steghide
steghide embed -cf cover.png -ef secret.txt -p "password123"

# 3. Add EXIF data
exiftool -Comment="Password hint: college_year" stego_master.png
```

## Tools Needed
- `stegsolve` - Visual steganography analysis
- `steghide` - Extract embedded data
- `exiftool` - Read metadata
- `binwalk` - File carving
- `strings` - Extract text
- Python with PIL - LSB extraction

## Solution Approach

### Step 1: Check Metadata
```bash
exiftool stego_master.png
strings stego_master.png | grep -i flag
```

### Step 2: Visual Analysis
```bash
stegsolve stego_master.png
# Check different bit planes
```

### Step 3: LSB Extraction
```python
from PIL import Image
img = Image.open('stego_master.png')
pixels = img.load()
# Extract LSB from each channel
```

### Step 4: File Carving
```bash
binwalk -e stego_master.png
```

### Step 5: Steghide (with password)
```bash
steghide extract -sf stego_master.png -p "college2026"
```
