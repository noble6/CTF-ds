## Solution

### Understanding the Obfuscation
The binary uses multiple obfuscation techniques:
1. **Rolling XOR** - XOR with a key that changes based on LCG (Linear Congruential Generator)
2. **Byte Shuffling** - Bytes are rearranged in a pseudo-random order
3. **Junk Byte Insertion** - Extra bytes inserted to confuse disassemblers
4. **Anti-disassembly** - Instructions that confuse static analysis tools

### Solution Script
```python
with open('obfuscated_challenge', 'rb') as f:
    binary = f.read()

# Find the obfuscated data (after the message)
message = b"Reverse engineer me to find the flag!\n"
message_offset = binary.find(message)
data_offset = message_offset + len(message)

# Extract obfuscated data
data = binary[data_offset:data_offset+1000]

# Remove junk bytes
cleaned = bytearray()
i = 0
while i < len(data):
    if data[i] in [0x90, 0xCC, 0xEB]:
        break
    cleaned.append(data[i])
    i += 1
    if i % 3 == 0:
        i += 2  # Skip junk

# Unshuffle
def unshuffle(data, seed):
    swaps = []
    state = seed
    for i in range(len(data) - 1, 0, -1):
        state = (state * 1103515245 + 12345) & 0xFFFFFFFF
        j = state % (i + 1)
        swaps.append((i, j))
    
    data = bytearray(data)
    for i, j in reversed(swaps):
        data[i], data[j] = data[j], data[i]
    return bytes(data)

unshuffled = unshuffle(cleaned, 1337)

# Rolling XOR decrypt
def decrypt(data, seed):
    result = bytearray()
    key = seed
    for byte in data:
        result.append(byte ^ (key & 0xFF))
        key = (key * 1103515245 + 12345) & 0xFFFFFFFF
    return bytes(result)

flag = decrypt(unshuffled, 0x42)
print(flag.decode())
```
