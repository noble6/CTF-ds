# Challenge 25: VM-Obfuscated RE
# Category: Reverse
# Points: 1000
# Difficulty: HARD

## Description
I created a custom virtual machine to protect my flag. The bytecode is encrypted and the VM has anti-debug features. Can you reverse engineer it and extract the flag?

**Files:**
- `vm_challenge.py` - The challenge binary (run this to check your flag)
- `bytecode.bin` - Encrypted VM bytecode (analyze this!)

## Anti-Debug Features

1. **Timing Checks**: Detects if execution is slowed (debugging)
2. **Debugger Detection**: Checks for attached debuggers
3. **Stack Corruption**: Corrupts stack if debugger detected
4. **NOP Sleds**: Inserts NOPs to confuse disassemblers

## Encryption Layers

1. **Bytecode Encryption**: XOR with key `0xDEADBEEF`
2. **Flag Storage**: XOR with key `0x42`
3. **Position-dependent**: Some operations depend on execution order

## Solution Approach

### Step 1: Decrypt Bytecode
```python
key = 0xDEADBEEF
decrypted = bytes([b ^ ((key >> (i % 4 * 8)) & 0xFF) 
                   for i, b in enumerate(encrypted)])
```

### Step 2: Disassemble VM Opcodes
Write a disassembler for the custom instruction set.

### Step 3: Understand Verification Logic
The bytecode:
1. Stores encrypted flag characters in memory
2. Reads user input
3. XORs input with 0x42
4. Compares with stored values

### Step 4: Extract Flag
The flag is stored as XOR'd characters. Extract and decrypt.
